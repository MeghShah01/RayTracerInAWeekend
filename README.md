# Custom Ray Tracer In Java
This project follows Dr. Peter Shirley's Ray Tracing in One Weekend, 
reimplemented in Java. The project currently implements the core ray tracing 
concepts from the book, with additional custom features planned for future 
development.

### Some features that currently have been added are:
***
1. Antialiasing
2. Lambertian Reflection
3. Gamma Correction
