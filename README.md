# Custom Ray Tracer In Java


This project is a Java implementation inspired by Dr. Peter Shirley's 
***Ray Tracing in One Weekend***. It implements the core ray tracing concepts 
introduced in the book, alongside additional features and 
planned improvements.

### Features:
***
1. Anti-aliasing
2. Lambertian Reflection
3. Gamma Correction

### Prerequisites:
***
- JDK 22 or later

### Future Improvements:
- Progressive Rendering
- Support for different materials
- Volumetric rendering
- SIMD optimization 

## How to Run the Application

1. **Clone the repository**

   Open your terminal in the desired directory and run:

   ```bash
   git clone https://github.com/MeghShah01/RayTracerInAWeekend.git
   ```

2. **Compile the project**

   You can open `main.java` in your preferred IDE or compile the project using `javac`.

   **Linux / macOS (Bash):**

   ```bash
   javac $(find . -name "*.java")
   ```

   **Windows:**

   ```cmd
   dir /s /B *.java > sources.txt
   javac @sources.txt
   ```

3. **Run the application**

   Run the main class using your IDE or terminal:

   ```bash
   java Main
   ```
