# Custom Ray Tracer In Java
This project fallows Dr. Peter Shirley's book *Ray Tracing in One Weekend*. 
It has been converted into Java code and in future releases there are a bunch
of custom features planed, so stay tuned!

### Some features that currently have been added are:
***
1. Antialiasing
2. Lambertian Reflection
3. Gamma Correction
